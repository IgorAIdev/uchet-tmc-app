# Облік ТМЦ — сторінка програми

Це зібрана програма (один HTML-файл) для показу і значки для головного екрана телефона. У сторінку вбудовано демонстраційну базу з умовними (вигаданими) даними; власний файл бази Excel відкривається на вашому пристрої й нікуди не передається.

Додати на головний екран: Android (Chrome) — меню ⋮ → «Додати на головний екран» / «Установити застосунок»; iPhone (Safari) — «Поділитися» → «На екран „Додому“».

## Папка `fes/` — «Бойові виплати» (демо для ФЕС)

Окрема програма з репозиторію `IgorAIdev/210FEC` (збірка `npm run package:site`). При оновленні «Обліку ТМЦ» папку `fes/` не видаляти.

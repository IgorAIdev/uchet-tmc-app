# Облік ТМЦ — сторінка програми

Це лише зібрана програма (один HTML-файл) і значки для головного екрана телефона. Даних тут немає: файл бази Excel відкривається на вашому пристрої й нікуди не передається.

Додати на головний екран: Android (Chrome) — меню ⋮ → «Додати на головний екран» / «Установити застосунок»; iPhone (Safari) — «Поділитися» → «На екран „Додому“».

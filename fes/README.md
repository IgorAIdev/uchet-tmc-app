# Бойові виплати — сторінка програми для показу

Зібрана програма (один HTML-файл) і значки для головного екрана телефона. Усі особи, документи й суми в ній вигадані.
Програма нічого не надсилає в мережу: файли Excel і Word читаються й зберігаються лише на вашому пристрої.

Додати на головний екран: Android (Chrome) — меню ⋮ → «Додати на головний екран»; iPhone (Safari) — «Поділитися» → «На екран „Додому“».
